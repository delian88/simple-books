# Simple Books

The idea is to develop the simplest accounting application for SMEs
Inflows will be captured from the bank statement as either capital, sales, loan, or payment from debtors.
Outflow will be captured from scanned third-party receipts as either purchase of asset, pay expenses, pay vendors, or pay loan.
The difference between sales revenue and business expenses will be reported as profit.
There should be a module for the balance sheet...ti record assets and liabilities of the company


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
